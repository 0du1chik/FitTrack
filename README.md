## Опис проєкту

У межах лабораторної роботи розширено семантичний HTML5-каркас вебсервісу **«FitTrack»** шляхом розробки доступних вебформ для адміністративного керування каталогом та збору зворотного зв'язку від користувачів (без використання CSS та JavaScript).

Основна мета — засвоїти правила створення доступних та семантично коректних вебформ, формування єдиного словника полів моделі, роботу з обмеженнями вбудованої HTML5-валідації та дослідження подій форм засобами Chrome DevTools.

---

## Реалізована функціональність

- **Словник полів моделі елемента каталогу:**
  * Визначено єдину типізовану модель вправи (атрибути `name`: `code`, `title`, `category`, `baseReps`, `difficulty`, `updatedAt`, `image`, `description`, `isBase`).

- **Панель адміністрування (`admin.html`):**
  * Створено навчальну імітацію адміністративного інтерфейсу з відповідною приміткою про відсутність серверного захисту.
  * Реалізовано доступну таблицю наявних елементів (`<table>`, `<caption>`, `scope="col"`) із посиланнями на редагування.
  * Розроблено форму додавання вправи з методом `GET`, згруповану у два `<fieldset>` із `<legend>` («Основні дані моделі» та «Параметри та специфікація»).
  * Додано підказки до полів складної структури через `aria-describedby` та перевірку за шаблоном `pattern="[A-Z]{2}-\d{3}"`.

- **Форма редагування (`admin-edit.html`):**
  * Створено форму з тотожною структурою, заповнену наявними значеннями елемента моделі (`value`, `selected`, `checked`, текст у `<textarea>`).
  * Додано приховане поле `<input type="hidden" name="id" value="1">` для передачі ідентифікатора.
  * Додано навігаційні «хлібні крихти» та кнопки з явним типом (`type="submit"`, `type="reset"`).

- **Форма відвідувача (`details.html`):**
  * Реалізовано окрему секцію відгуку (`<section id="feedback-section" aria-labelledby="feedback-heading">`).
  * Поля персональних даних оснащено атрибутами автозаповнення (`autocomplete="name"`, `autocomplete="email"`, `autocomplete="tel"`).
  * Реалізовано групу радіокнопок оцінки у `<fieldset>`, текст коментаря та прапорець згоди.
  * Додано інтерактивний список підказок для вибору обладнання через `<datalist id="equipment-options">`.

- **Дослідження у Chrome DevTools:**
  * Проаналізовано кодування GET-запитів (`Query String Parameters`), поведінку невідміченого прапорця та завантаження файлів (`input type="file"`).
  * Перевірено вбудовану валідацію та продемонстровано некорисність клієнтського захисту шляхом видалення атрибута `required` у DOM-дереві.
  * Простежено послідовність виклику подій форми (`input`, `change`, `invalid`, `submit`, `reset`) у консолі за допомогою `monitorEvents()`.
