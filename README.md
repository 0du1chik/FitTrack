## Опис проєкту

У межах лабораторної роботи розроблено семантичний HTML5-каркас каталогу силових та функціональних вправ **«FitTrack»** без використання засобів візуального оформлення (CSS). 

Головна мета — побудувати логічну, доступну для скрінрідерів та валідну за стандартами W3C структуру сторінки, готову до подальшої стилізації та підключення REST API у наступних роботах курсу.

## Реалізована функціональність

* **Семантична архітектура та орієнтири:**
  * Застосовано орієнтири `<header>`, `<nav>`, `<main>`, `<footer>` та допоміжний блок `<aside>`.
  * Логічне структурування контенту виконано через секційні контейнери `<section>`.
  * Кожна картка вправи оформлена як незалежна автономна сутність за допомогою тегу `<article>` всередині елементів списку `<ul>`.

* **Доступність (Accessibility):**
  * Вибудувано сувору ієрархію заголовків (`h1` ➔ `h2` ➔ `h3`) без пропуску рівнів.
  * Секції та картки логічно зв'язані зі своїми заголовками за допомогою атрибута `aria-labelledby`.
  * Поля форми фільтрації явно з'єднані з підписами (`<label for="...">` ↔ `<input id="...">`).

* **Адаптивні медіа та продуктивність:**
  * Зображення оптимізовано за допомогою атрибутів `srcset` та `sizes` (економія мобільного трафіку без участі CSS).
  * Для кожного зображення вказано чіткий атрибут `alt`, а також атрибути розмірів `width` та `height` для запобігання зсуву макета (CLS).
  * Додано сучасні атрибути завантаження: `fetchpriority="high"` для першого екрана та `loading="lazy"` для інших карток.

* **Машиночитані дані:**
  * Дати верифікації техніки оформлено за допомогою тегу `<time datetime="YYYY-MM-DD">`.
  * Числові значення (повторення/час) розмічено через `<data value="...">`.
